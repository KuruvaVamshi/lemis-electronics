# Impressive Interactive UI Skill

## Rule of Non-Static Design
**Never leave any UI section plain or static.** Every section must offer the user an engaging, innovative, and tactile interactive mechanism tailored to the subject matter.

## Mandatory Section Innovation Patterns

1. **Brand Values / Pillars / Principles**:
   - Do NOT use plain 3-box or 5-box grids.
   - Use interactive consoles with tabbed proof inspectors, live metrics, certificate previews, interactive timelines, or 3D morphing showcases.

2. **Specifications & Amenities**:
   - Use 3D card tilt with specular highlights, interactive before/after sliders, material deep-dive inspectors, or exploded architectural views.

3. **Projects & Portfolios**:
   - Use stacking pinned cards, dual-perspective viewports, floor plan layer switchers, or 4K live walk-through modals.

4. **Masterplans & Locations**:
   - Use pulsing interactive hotspots with preview cards, distance/drive-time calculators, or layer toggles.

5. **Data & Metrics**:
   - Use animated numerical counters with live location breakdowns or interactive sliders.

6. **FAQs & Governance**:
   - Use interactive accordion drawers with instant document downloads or verification badges.
